# Meeting Live

[English](README.md) | 简体中文

嵌入 Markdown 笔记正文的实时会议工作台：本地录音，用火山引擎（字节跳动）流式语音识别实时转写，每隔几分钟由 AI 生成阶段摘要，并能把会议或已有录音整理成结构化纪要。

仅支持桌面版（在 macOS 上测试），需要 Obsidian 1.11.4 或更高版本。界面目前为简体中文。

## 功能

- **正文内嵌会议卡片**：`meeting-live` 代码块在实时预览和阅读视图中都渲染为可交互的卡片，上下可以照常写笔记。
- **本地录音**：边录边写入库中（Opus 或 WAV 无损），分段保存，异常退出后也能播放，在卡片里按统一时间轴回放。
- **实时转写**：实时显示识别中的文字，断线自动重连，无法转写的时段会明确标出。转写失败不影响录音。
- **阶段摘要**：每累计 N 分钟会议时长（默认 5 分钟），由 OpenAI 兼容模型把新增内容按发言顺序列成要点，每条用颜色标记标明是事实、观点、待办还是未决问题。每条都能跳回对应转写，转写中找不到的数字会被标记。
- **会议纪要**：会后根据转写、阶段摘要和你的笔记生成纪要，Prompt 可自行修改。
- **录音生成纪要**：从库中或电脑上选一个录音文件，带说话人转写后整理成纪要写入当前笔记。在后台进行，笔记中显示进度横条。

## 配置

1. 安装并启用插件。
2. 打开「设置 → Meeting Live」，填写：
   - **火山引擎语音识别**：新版控制台填 API Key，旧版控制台填 App ID 和 Access Token，再填已开通服务的 Resource ID。实时转写使用流式识别（如 `volc.seedasr.sauc.duration`），录音生成纪要使用录音文件识别（如 `volc.seedasr.auc`）。可以用「测试」按钮检查凭证。
   - **LLM**：任意 OpenAI 兼容的 Chat Completions 接口（地址、模型、API Key），可设置推理强度。
   - **Prompt**：默认提示词简短通用，建议换成自己的。

## 使用

- **实时会议**：在命令面板或左侧栏执行「插入会议组件」，点击开始录音。切换笔记或视图不会中断会议，状态栏会显示录音状态。
- **录音生成纪要**：打开一篇笔记（空白笔记也可以），在命令面板或左侧栏执行「录音生成访谈记录」。

## 数据与隐私

网络使用：

- **火山引擎语音识别**（`openspeech.bytedance.com`）会收到你的音频：录音时实时上传，或在录音生成纪要时上传整个文件。
- **你配置的 LLM 接口**会收到转写文本、阶段摘要，以及生成纪要时你选择的笔记内容。
- 不向其他任何地方发送数据，没有统计上报。

本地保存：

- 录音、原始转写、摘要和会议信息保存在库中的会议目录（默认 `Meetings/`）。AI 生成的内容单独存放，不会覆盖原始转写和录音。
- 设置和提示词只保存在库内插件目录的 `data.json` 中。
- API Key 保存在 Obsidian 的密钥存储中，设置文件里只记录密钥名称。

请确保所有参会者同意录音和使用云端服务处理。

## 限制

- 普通麦克风只能录到现场声音。要录线上会议对方的声音，需要用 BlackHole 等虚拟声卡转接系统音频，并在设置中选择该输入设备。
- 说话人编号按声音自动区分，不代表身份。
- AI 摘要和纪要可能有误，请对照转写和录音核实事实与数字。
